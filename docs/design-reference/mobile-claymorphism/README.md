# Infinity Blog — Mobile Claymorphism Asset Pack

This pack translates the approved visual direction into organized references for the small-screen experience.

## Included

- `reference/InfinityBlog_Mobile_Claymorphism_Board.png` — complete UI design board.
- `reference/screens/` — separate mobile screen references: home feed, article with Report Post, report modal, notifications, profile, and mobile drawer.
- `reference/components/` — references for buttons, inputs, category chips, status badges, article cards, bottom navigation, the clay icon system, and soft abstract surfaces.
- `icons/clay-tiles/` — individually cropped, enlarged clay-style icon tiles (not transparent vector icons; use as visual references or small decorative tiles after checking fit).
- `reference/decorative/` — three surface-sample crops for visual reference.
- `ANTIGRAVITY_PROMPT.md` — implementation prompt for your existing project.
- `mobile-claymorphism-reference.css` — optional illustrative CSS tokens/classes; have Antigravity adapt these to the existing stylesheet rather than blindly replacing it.

## Important

The PNGs of full screens and component sheets are visual references, **not finished web components**. Do not place full screen screenshots into the live page as backgrounds. Recreate the UI with the existing PHP templates, semantic HTML, CSS, and the project's existing icon system or inline SVGs. Keep desktop glassmorphism unchanged and apply claymorphism at mobile breakpoints. Preserve all existing functionality and user data.
